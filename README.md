# life-os

A personal life-organization system: one place to keep track of goals, projects, routines, and the notes that support them.

The aim is a simple, plain-text setup that makes it easy to:

- **Capture** tasks, ideas, and commitments as they come up
- **Plan** around longer-term goals and the projects that move them forward
- **Review** progress regularly (daily, weekly, and beyond) and adjust course
- **Keep reference material** (notes, checklists, and routines) close at hand

Everything lives in version control, so the system's history is preserved and it stays portable across tools and devices.
